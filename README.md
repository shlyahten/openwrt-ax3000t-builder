# Сборщик OpenWrt для Xiaomi Mi Router AX3000T (AmneziaWG + Podkop)

Автоматизированная сборка кастомной прошивки **OpenWrt 25** через **GitHub Actions** и официальный **OpenWrt Image Builder** для роутера **Xiaomi Mi Router AX3000T**.

В прошивку уже интегрированы пакеты для обхода блокировок: **AmneziaWG 3.x** с защитой от DPI и **Podkop** с веб-интерфейсом LuCI на базе ядра **sing-box**.

---

## 📌 Характеристики сборки

- **Целевое устройство:** Xiaomi Mi Router AX3000T (RD03 / RD23)
- **Архитектура / Target:** `mediatek/filogic` (MT7981B, aarch64_cortex-a53)
- **Профиль Image Builder:** `xiaomi_mi-router-ax3000t`
- **Версия OpenWrt по умолчанию:** `25.12.5` (ветка OpenWrt 25 с современным пакетным менеджером **apk** / `packages.adb`)

### Включённые пакеты:
- **AmneziaWG 3.x:**
  - `kmod-amneziawg` — модуль ядра AmneziaWG с поддержкой расширенной обфускации трафика (`Jc`, `Jmin`, `Jmax`, `S1-S4`, `H1-H4`, `HeaderProtectionKey` и др.).
  - `amneziawg-tools` — утилита управления интерфейсами `awg`.
  - `luci-proto-amneziawg` — протокол AmneziaWG для веб-интерфейса LuCI с поддержкой импорта конфигураций.
- **Podkop:**
  - `podkop` — служба выборочной маршрутизации трафика на базе sing-box / tproxy.
  - `luci-app-podkop` — веб-интерфейс управления правилами и списками блокировок в LuCI.
- **Сетевой стек и утилиты:**
  - `sing-box` — ядро проксирования трафика.
  - `luci`, `luci-ssl`, `luci-app-firewall` — полный веб-интерфейс с поддержкой HTTPS.
  - `ca-bundle`, `curl` — доверенные сертификаты и HTTP-клиент.
  - `tcpdump`, `sqlite3-cli` — диагностика сети и работа с базами данных IP/доменов.

## 🚀 Как запустить сборку в GitHub Actions

Сборка происходит полностью в облаке GitHub и занимает около 3–5 минут:

1. Перейдите во вкладку **Actions** в верхней панели вашего репозитория.
2. В левой колонке выберите воркфлоу **Build OpenWrt for Xiaomi AX3000T**.
3. Справа нажмите кнопку **Run workflow**.
4. Заполните (или оставьте по умолчанию) параметры:
   - **OpenWrt Release Version:** `25.12.5` (или другая поддерживаемая версия).
   - **Target Architecture:** `mediatek/filogic`.
   - **Device Profile:** `xiaomi_mi-router-ax3000t`.
   - **Custom packages:** список пакетов (по умолчанию уже включены AmneziaWG, Podkop и sing-box).
   - **Publish GitHub Release:** `true` (автоматически создаст релиз с готовым файлом).
5. Нажмите зелёную кнопку **Run workflow** для старта.

По завершении сборки файл прошивки доступен в двух местах:

   - Откройте завершившийся запуск в разделе **Actions**.
   - Внизу страницы в секции **Artifacts** скачайте архив `openwrt-25.12.5-xiaomi_mi-router-ax3000t.zip`.

## ⚡ Прошивка роутера (Sysupgrade)

> ⚠️ **Внимание:** Данная прошивка предназначена для версии роутера Xiaomi AX3000T на процессоре MediaTek Filogic MT7981B. Не используйте её для аппаратных ревизий на чипах Qualcomm (например, RD03v2).

### Если на роутере уже установлена OpenWrt:
1. Откройте панель управления **LuCI** (`http://192.168.1.1`).
2. Перейдите в меню: **System** -> **Backup / Flash Firmware**.
3. В секции **Flash new firmware image** нажмите кнопку **Flash image...**.
4. Выберите скачанный файл `*sysupgrade.bin`.
5. Дождитесь проверки контрольной суммы SHA256 и нажмите **Continue**.
6. **О сохранении настроек (Keep settings):**
   - **При обновлении в рамках OpenWrt 25:** можно оставить отметку **Keep settings**.
   - **При переходе с OpenWrt 23.x / 24.x на OpenWrt 25.x:** **рекомендуется снять отметку Keep settings** (чистая установка), так как в ветке 25 произошёл переход с менеджера пакетов `opkg` на `apk`. Сохраните нужные конфигурации заранее.
7. Не отключайте питание роутера в процессе прошивки (индикаторы помигают, и через 2-3 минуты роутер будет доступен по адресу `192.168.1.1`).

## ⚙️ Первичная настройка AmneziaWG и Podkop

### 1. Настройка AmneziaWG
1. В LuCI перейдите в **Network** -> **Interfaces** -> **Add new interface...**.
2. Укажите:
   - **Name:** `awg0`
   - **Protocol:** `AmneziaWG`
3. Нажмите **Create interface**.
4. Введите параметры подключения из вашего файла `.conf` (PrivateKey, IP-адрес с маской, порт, параметры обфускации: Jc, Jmin, Jmax, S1, S2, H1–H4).
5. В секции **Peers** добавьте пир:
   - Введите PublicKey сервера, Endpoint host и порт.
   - **Allowed IPs:** `0.0.0.0/0` (или нужные подсети).
   - **Route Allowed IPs:** для работы с Podkop снимите галочку автоматических маршрутов (Podkop направляет трафик самостоятельно через таблицы маршрутизации).
   - **Persistent Keep Alive:** `25`.
6. Во вкладке **Firewall Settings** создайте новую зону `awg` или включите в зону `wan`.
7. Нажмите **Save & Apply**.

### 2. Настройка Podkop
1. В LuCI откройте меню **Services** -> **Podkop**.
2. В основных настройках:
   - Включите службу (**Enable**).
   - Выберите тип VPN / исходящего интерфейса: интерфейс AmneziaWG (`awg0`).
   - Настройте списки доменов и антиблокировки.
3. Нажмите **Save & Apply**.

## 🛠 Кастомизация сборки

### Добавление собственных конфигурационных файлов:
Если вы хотите, чтобы в прошивку были сразу вшиты преднастроенные файлы (например, `/etc/config/network`, кастомные скрипты или SSH-ключи):
1. Создайте в корне репозитория директорию `files/`.
2. Поместите внутрь файлы с сохранением структуры каталогов OpenWrt (например, `files/etc/config/network` или `files/etc/dropbear/authorized_keys`).
3. Скрипт сборки автоматически подхватит директорию `files/` и встроит файлы в корневую файловую систему прошивки.

### Изменение списка пакетов:
В файле `.github/workflows/build.yml` в секции `inputs.packages.default` можно изменить базовый список пакетов по умолчанию, удалив ненужные или добавив дополнительные (например, `nano`, `htop`, `wireguard-tools` и др.).

### Автоматическая интеграция ключей и репозиториев:
Сборщик автоматически вшивает публичные ключи подписи и адреса репозиториев (`2grey` AmneziaWG) непосредственно в файловую систему роутера:
- Для **OpenWrt 25+ (APK)**: ключи сохраняются в `/etc/apk/keys/`, а репозиторий — в `/etc/apk/repositories.d/amneziawg.list`.
- Для **OpenWrt 24 (OPKG)**: ключи сохраняются в `/etc/opkg/keys/`, а репозиторий — в `/etc/opkg/customfeeds.conf`.

Благодаря этому после прошивки вы сможете обновлять пакеты AmneziaWG через стандартный `apk add / opkg upgrade` без необходимости заново искать и импортировать ключи разработчика.
